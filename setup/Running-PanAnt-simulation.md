Running PanAnt simulation
=========================

Set up the control directories for each experiment/ensemble member.

Begin with the default configuration using the chosen commit:

    payu clone -s ac99c202a8e43eb2b8f40bc470dd9a6b3507a30f -b default https://github.com/ACCESS-NRI/access-om3-configs ac99c

Run this control experiment until spun up. Then use the instructions in `Set-up-different-bathymetry-configs.md` to create the different configs and run them.
